# AI Image Generation Prompts for Volunteer Cards

Generate these images at **1200x520px** for optimal card display.

## Style Guidelines
- Professional, modern design
- Patriotic color palette (reds, whites, blues)
- Clean, bold imagery
- No text overlays (titles are in the UI)
- Appropriate for civic/government context

---

**Prompt:**
```
Create a professional 1200x520px image representing local government advisory boards and civic leadership. Show a modern government building or council chamber with diverse people collaborating around a table. Include elements like documents, laptops, and American flags subtly in the background. Use a patriotic color palette of navy blue, white, and subtle red accents. Professional, clean, inspiring composition that conveys citizen participation in local government. No text overlays.
```

**Alternate Prompt:**
```

Feature a stylized illustration of people sitting at a circular table in a modern government setting, with city skyline visible through windows. Use gradients of deep blue transitioning to lighter blue, with white and red accent elements. Convey collaboration, leadership, and community service. Professional, modern, inspiring. No text.
```

## Usage Instructions

1. Generate images using your preferred AI tool (Midjourney, DALL-E 3, Stable Diffusion)
2. Ensure final size is **1200x520px** exactly
3. Save with descriptive filenames:
   - `jointab-advisory-boards.jpg`
   - `justserve-community.jpg`
   - `voa-nonprofit.jpg`
   - `americorps-national-service.jpg`
   - `volunteer-gov-parks.jpg`
4. Upload via the admin panel at `/admin/resources` (or future `/admin/volunteers`)
5. Follow the streamlined upload process documented in `STREAMLINED_CARD_UPLOAD.md`
